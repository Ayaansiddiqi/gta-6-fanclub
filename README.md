## GTA VI Fan Club 🎮

A GTA VI fan website built as a front-end development project.

## About

This project is a fan-made website inspired by Grand Theft Auto VI.
I built it to practice and improve my HTML, CSS, JavaScript, and responsive web design skills.

## ✨ Features

* Responsive navigation bar
* Responsive hero section
* Mobile hamburger menu
* GTA VI themed design
* Responsive layout for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

## 🎯 Purpose

This project is part of my journey toward becoming a professional web developer and is primarily focused on improving my front-end development skills.
